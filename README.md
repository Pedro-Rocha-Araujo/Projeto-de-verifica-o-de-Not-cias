# 🧠 Verificação de Notícias com Agentes de IA 🧠

**`📁 Descrição dos arquivos 📁`**

**1- venv**
    Ambiente virtual onde as bibliotecas estão baixadas
    Guia de uso:
    1- Abrir o terrminal
    2- Digitar o comando: venv\Scripts\activate
    3- Caso receba um erro digite: powershell -ExecutionPolicy Bypass -File .\venv\Scripts\Activate.ps1

**2- env**
    Esse arquivo é onde está a chave de API do Chatgpt

**3- agentes.py**
    Esse arquivo é a base onde começ~ei a criação dos agentes (Como um esboço), sem Interface

**4- interface2.py**
    Essa é a versão final já com interface

**`🚀 Como usar o código 🚀`**

**1-** Digite no terminal o comando: streamlit run ""Caminho do arquivo"/interface2.py"
obs: atente-se com a letra do disco onde os arquivos estão arquivados.

**2-** Após isso, uma tela no terminal pedirá seu E-mail, porém é possível pular apenas digitando a tecla enter

**3-** Seu navegador de internet irá abrir o sistema já em sua interface, então é só realizar suas checagens.
